# Decision records

Use a decision record for an accepted or reversed choice that changes the application stack, canonical data contract, parser, audio backend, platform boundary, dependency, license policy, supported MIDI contract, or target platform.

Copy `0000-template.md` to the next four-digit number and a short kebab-case title. Keep superseded records; change their status and link to the replacement so the reasoning remains visible.

[0001 — MVP musical interpretation and practice boundaries](0001-mvp-musical-contracts.md) records the shared planning contract. Its implementation checks are pending. The M0 Godot go/no-go decision remains a separate required record; no planning acceptance substitutes for measured stack evidence.

[0002 — Godot M0 evaluation build](0002-m0-evaluation-build.md) records prototype limits, dependency screening, and the threaded web mitigation. It does not close the final stack gate.

[0003 — Practice feedback](0003-practice-feedback.md) records the score-first UI, one-measure phone layout, idle rendering policy, and expanded tempo/volume controls.

[0004 — Score navigation](0004-score-navigation.md) replaces the single-measure phone view with default scrolling, adds manual screen pages, corrects high-density mobile coordinates, and records the conditional stack recommendation.
