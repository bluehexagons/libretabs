# MVP software audit evidence

Date: 2026-09-07

## Findings addressed

- Keyboard measure navigation no longer reads the song while startup or replacement
  import is in progress.
- Saved display scale is restricted to the three supported finite values in both
  the host adapter and web bridge. Missing, corrupt and unsupported values recover
  to 100% without entering layout calculations.
- Imported display names remove C0/C1 controls and invisible Unicode formatting
  controls while preserving ordinary Unicode names.
- Continuous score notes use the drawable width after the leading inset, keeping
  the final note grid inside its measure barline.
- Action-button hold help handles direct screen-touch and screen-drag events in
  addition to browser-emulated mouse events.
- Left and right player rails no longer inherit wide-screen centering margins.
  Side choices adapt below the music in narrow portrait, complementing the existing
  short-landscape adaptation.

## Automated checks

`python3 scripts/verify.py` passed on Godot 4.7.2 with 6,225 core checks, 363
practice UI checks, five web/offline checks, project import, editor load,
intentional-failure propagation, application boot and whitespace validation.
Regression checks cover invalid scale values, sanitized Unicode names, startup
arrow input, touch hold-help cancellation, note bounds, score pointer geometry,
wide side rails and narrow-portrait adaptation.

## Export and browser review

`infra-tools agent doctor --capability development --json` reported healthy Godot,
Node and Go toolchains. `infra-web publish godot --json` completed a release export,
and `infra-web doctor libretabs-prototype` reported the managed HTTPS build healthy.

The T3 collaborative Chromium preview checked 1280 × 800, 390 × 844, 844 × 390
and 1920 × 1080 viewports. The page and canvas fit each viewport without document
overflow. The phone portrait retained large controls and upcoming music; short
landscape retained the complete staff and six tab lines beside the controls; and
the wide left rail remained compact. A reload with `Infinity` stored as the web
display scale recovered to a ready, idle player with no console error or failed
network request.

## Evaluation limits

This pass does not close the roadmap's hardware and cross-browser gates. Timing
and input latency still need human review with representative audio devices, and
the web export still needs Firefox, Safari and physical touch-device coverage.
