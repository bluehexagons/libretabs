# Prototype.19 release verification

Date: 2026-10-21. This records publication and bounded checks of the evaluation
prototype; musical, learner and physical-platform acceptance gates remain open.

## Publication

The public prerelease
[`0.0.1-prototype.19`](https://github.com/bluehexagons/libretabs/releases/tag/v0.0.1-prototype.19)
uses source commit `4f448292eafd32090c5cf9ce5562c07003c5b20b` and the committed
[release notes](../../release/notes/0.0.1-prototype.19.md). The tag resolves to that
commit. The [normal CI](https://github.com/bluehexagons/libretabs/actions/runs/39679744904)
and [release workflow](https://github.com/bluehexagons/libretabs/actions/runs/39679984121)
passed, including packaging, publication and Pages deployment.

Local `python3 scripts/verify.py --full` passed in 65.23 seconds: 21 commands,
68 Python tests, 30 JavaScript tests and 8,137 structured GDScript checks, plus
toolchain, import, failure-exit, boot and whitespace checks. CI also reproduced
the generated inputs exactly. The intensive UI matrices and extra editor audit
were not run; they remain optional under the current suite policy.

## Downloaded packages

All five published assets were downloaded: web, Windows x86_64 and Linux x86_64
ZIPs, `manifest.json` and `SHA256SUMS`. Manifest/checksum agreement, ZIP integrity,
safe archive paths, exact version/source/target identities and bundled Apache
and Godot notices passed. All packages identify the pinned engine
`4.7.2.stable.official.ed1daf0bf`. The web ZIP's nine offline assets matched their
manifest hashes.

The downloaded Linux executable ran through the shared Debian desktop with
fresh application data and `/usr/bin:/bin` as PATH, excluding the Godot editor.
Quick start rendered, Start practicing opened the score, and keyboard playback
advanced to measure 2 before pausing with synchronized staff/tab highlights.
The app closed with exit code 0. Its runtime log contained the known unsupported
V-Sync warning from the software graphics driver and no script errors. This is
a Debian runtime check; Windows and CachyOS runtime checks remain open.

## Public web checks

The [guide](https://bluehexagons.github.io/libretabs/) displayed prototype.19,
linked to its exact downloads and showed the current menu paths. Both hosted
players' nine offline assets matched their deployed manifest hashes over HTTPS;
JavaScript and WASM MIME checks passed. The Pages players use worker-provided
isolation rather than server COOP/COEP headers.

A fresh incognito profile in public Chromium 154/T3 preview rendered the
[threaded player](https://bluehexagons.github.io/libretabs/play/) at 1280 × 800
and the [compatibility player](https://bluehexagons.github.io/libretabs/play-compatible/)
at 390 × 844 (device pixel ratio 2). About visibly showed the exact release
version in both. On the narrow player, searching for “about”, opening a result
and going Back preserved the search and keyboard focus; the About LibreTabs
result remained reachable.

Both variants advanced playback and paused with zero active voices and live
notes. The threaded sample paused at tick 534.28 and reported two startup
underruns. The compatibility sample paused at tick 868.64 with zero reported
underruns, but playback rendered around 7 FPS in this managed preview and
required a longer sample to pass the count-in. These are functional checks,
not independent audible-timing or foreground-browser performance passes. T3
reported the preview hidden while document visibility was visible, so the
results do not identify the source of the slowdown.

Both players initialized in the ready state after an online reload, with inputs
off and zero active voices. Complete-cache status and the client release IDs
matched the deployed manifests:

- Threaded: `da38b9d7ae343a541b92fd60e7f88dbd669f9ea2a180127e0adb67b446137929`.
- Compatibility: `4a37bf7d60995378b42dfb820020224cd264d4e7b4a0e7b910168471bb9508e9`.

No application console errors or failed requests were observed. T3 has no
network-offline emulation, so network-disabled restart was not repeated.
Asset hashes, cache readiness and online reload do not replace that check.

## Evidence and remaining checks

Local logs, downloaded assets, desktop captures and compact package/browser
reports are retained under ignored `build/release-2026-10-21/`, following the
[artifact-retention policy](../artifact-retention.md). Published workflow logs
and release assets provide durable external evidence.

Physical MIDI/microphone behavior, independent audible timing, normal foreground
browser profiling, Safari/Firefox, Windows/CachyOS, physical phones and musician
and beginner acceptance remain open. Native packages remain unsigned. The
release notes provide focused checks for menu navigation and input recovery;
this release adds no new MVP scope or distribution destination.
