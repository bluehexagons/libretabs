# Security reports

LibreTabs is an experimental local-first prototype. Only the newest prototype is
maintained; no stable support window is promised yet.

For a vulnerability, use GitHub's **Security → Report a vulnerability** on
https://github.com/bluehexagons/libretabs/security/advisories/new when private reporting
is enabled. Do not put credentials, private MIDI, or exploit details in a public
issue. If private reporting is unavailable, open an issue requesting a private
contact without including sensitive details.

Include the version/commit, platform, impact and a minimal reproduction you have
permission to share. The runtime imports local files and stores settings locally;
malformed-input crashes, unsafe export contents and unexpected data transmission
are security-relevant. Maintainers will coordinate a fix and disclosure; no paid
bug-bounty program or response-time guarantee is offered.
