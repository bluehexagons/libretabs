# License scope

LibreTabs intentionally separates software from reusable educational and creative material.

| Material | Default license |
| --- | --- |
| Application and library source code, test code, build scripts, project/export configuration, and standalone source-code examples | [Apache License 2.0](../LICENSE) |
| Project-authored documentation, lesson text, illustrations, original music, and MIDI test/lesson fixtures | [CC0 1.0 Universal](CC0-1.0.txt) |
| Third-party code, fonts, binaries, media, and fixture data | The work's own declared license; see its notice and [`third_party/README.md`](../third_party/README.md) |

A file-specific SPDX identifier or license notice overrides these defaults. The standard license texts and notices are themselves governed by their stated terms.

Only contribute CC0 material that you created or have authority to dedicate. Do not copy a song, illustration, tablature, MIDI file, sample, font, or other work into the project merely because it is available at no cost. Inclusion in LibreTabs never relicenses third-party work.

Generated exports are combinations of software and content; their accompanying notices must preserve every applicable license. This policy is intended to make project-created learning material worry-free to reuse while keeping third-party obligations accurate.

SPDX identifiers: `Apache-2.0` and `CC0-1.0`.
