# LibreTabs 0.0.1-prototype.12

Evaluation build for manual testing; the lesson-based course and musical/platform
acceptance work remain incomplete.

[Play and read the practice guide](https://bluehexagons.github.io/libretabs/).
After an update, finish your session and reload if an older cached player appears.
Find the running version in **Menu → About LibreTabs**.

## What changed since prototype.11

- **Songs** now offers 30 local teaching arrangements, including *Amazing Grace*,
  *Aura Lee*, *Silent Night*, *Simple Gifts*, *Sakura Sakura* and *The Entertainer*.
  All songs received a source/timing review; corrections include Greensleeves'
  rhythm, Aura Lee's melody and Canon's bass timing. These remain short teaching
  realizations awaiting musician acceptance.
- **Tuner & listening** has separate acoustic and electronic piano profiles and
  more sensitive soft-note detection, plus voice, bass, ukulele, violin and
  general/custom-note targets. **Tuner on** temporarily pauses listening;
  **Mute practice audio** silences practice output while its position continues, helping
  keep speaker playback out of the microphone. Listening still estimates one
  note at a time and does not assess chords.
- Regular practice reserves stable room for changing note and listening messages,
  reducing score resizing during playback. Muting an individual part preserves
  the current timeline. MIDI connection cleanup avoids stale or stuck inputs.
- Buttons, sliders, switches and dropdowns use clearer surfaces and scalable
  artwork. Upcoming notes have quiet curved underlines. Sounding staff noteheads
  become slightly larger and bolder, preserving filled/hollow shapes; sounding
  tab numbers retain rounded outlines. Disabled dropdowns no longer take focus,
  and large-text playback-position labels keep words intact.
- Printing has more reliable cancellation, tuner guidance is clearer, and
  browser file-picking/release handling has additional safeguards.

## Suggested manual checks

- Browse, Listen and Try several familiar songs. Check rhythm, pitches, bass
  timing and readability; report the song and measure for musical concerns.
- Try an electronic piano through its speakers into a microphone at a comfortable
  volume. Select the electronic piano profile, calibrate room noise and adjust
  sensitivity. Toggle Tuner on and Mute practice audio during playback, then restore sound.
- Play, pause, seek, change tempo, repeat a short loop and mute a part. Check that
  sound and highlights remain synchronized and the score stays steady.
- Compare regular and Theater views, portrait/landscape, 200% text, keyboard
  navigation and Light/Dark/Midnight. Confirm that sounding quarter and half notes
  remain recognizable and disabled controls are skipped.
- Import an original or redistributable MIDI file; cancel or reject a malformed
  replacement and confirm that the previous song remains available. Test saved
  settings, offline reload after the ready message, and printing/cancellation.

## Downloads

- Web ZIP: for an HTTPS host or itch.io HTML upload; not a double-click offline app.
- Windows x86_64 ZIP: extract completely and run `LibreTabs.exe`.
- Linux x86_64 ZIP: extract completely and run `./libretabs.x86_64`.

Native builds are unsigned. Download only from this release and verify
`SHA256SUMS`. No Godot installation is required. Report blocked launches with
the OS and message; keep operating-system security protections enabled.

## Known limits and feedback

Generated guitar fingering, simplified notation, procedural sounds and suggested
levels remain under evaluation. Imported MIDI stays on the device for the current
session. Real piano/microphone acceptance, physical MIDI controllers, independent
audible timing, Safari/Firefox, Windows runtime and physical phone checks remain
open. A successful export is not a device test.

Post-publication checks verified all downloaded checksums, ZIP integrity and
build identities. The downloaded Linux package and preferred threaded Pages
player passed short play/pause checks. The compatibility player rendered, but
playback stalled with an audio-start warning in this T3 Code environment at low
frame rates, including at phone size. Use the main player or a native package
for practice; compatibility audio needs further foreground-browser testing.
Network-disabled browser restart was not re-tested in this audit.

Report the running version, OS/browser, input/audio devices, steps, expected
result and actual result at https://github.com/bluehexagons/libretabs/issues.
Use original or redistributable MIDI and remove private details from screenshots.
