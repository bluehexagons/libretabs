# LibreTabs 0.0.1-prototype.18

This evaluation build improves seeking, count-in cues and phone navigation.

- Mouse hover shows delayed, short captions. Hints stay quiet while playing or
  using the keyboard, and no longer cover the score. F1 and touch-and-hold keep
  the full control explanations; holding a mouse button no longer opens help.
- Small score seeks ease the music into place; larger jumps briefly fade.
  Reduced Motion makes seeking immediate. Seeking and previews stop at the
  actual song end, including partly filled final measures. Seeking to the end
  offers Replay.
- Count-in shows changing beat dots as well as a number, both in Play and beside
  the starting music. The indicators follow the same audible transport.
- Every regular interface has a position slider in portrait, landscape and
  manual pages. The compact readout shows measure number and elapsed time.
- Phone Focus puts a compact toolbar above the music; Touch puts the timeline
  in its thumb console; Workspace uses a narrow rail with tool icons when space
  permits. The smallest windows and enlarged text retain the common fit rules.

Please try mouse hover while reading, playing and using keyboard shortcuts.
Seek forward/backward repeatedly, scrub while playing, and tap the padded end
of a partly filled final measure. Check count-in dots at ordinary and slowed
speeds. Compare interfaces on your phone, rotate it, and try larger text with
listening enabled. Playback, loop and tuner state should survive interface changes.

Automated navigation/layout checks and native rendering checks pass. Native
caption creation and keyboard suppression were also checked. The managed HTTPS
export is healthy; collaborative browser snapshots still fail, so web interaction,
physical phone behavior and audible timing remain manual checks. This remains
an evaluation prototype; musician and beginner acceptance is still open.
