# LibreTabs 0.0.1-prototype.10

Evaluation prototype, not the completed lesson-based MVP.

[Play and read the practice guide](https://bluehexagons.github.io/libretabs/).
If an older cached player appears after updating, finish your session and reload.

## What changed

- Quick start now leads with **Start practicing** and three short steps. Layout and song choices remain one tap away; the guide adapts to narrow and short windows.
- Play notes on the on-screen piano, or connect a MIDI controller where the browser or desktop supports it. Played pitches appear against the score, with pitch and timing feedback while the song continues.
- **Tuner & listening** can estimate one microphone note at a time for piano, acoustic guitar, or electric guitar. It shows pitch and cents, offers a repeatable room setup, and can compare single notes during practice. Microphone access starts only when you choose **Start microphone**.
- Optional hands-free note commands can play or pause, replay, and adjust speed while the tuner microphone is active. They are off by default, can be disabled in Settings, and require a wake phrase followed by a repeated command note.
- Choose among generated practice sounds, including Synth piano, and optionally add room ambience or soft chorus. Dark and Midnight appearances and more background choices are available.

## Useful checks for testers

- Start with the built-in exercise, try the piano keyboard, and compare its note markers with the staff. Connect a MIDI keyboard if you have one; check note release and sustain pedal behavior.
- With headphones or muted speakers, start the microphone, run room setup, and compare a single sustained note with a separate tuner. Try quiet and noisy rooms, then stop the microphone and confirm the tuner clears.
- If you enable hands-free commands, try the sequence shown in Settings. Check that an incomplete phrase or disabling the option does nothing.
- Resize Quick start to a narrow portrait or short landscape window. **Start practicing** should be visible before scrolling; choosing it should not start audio.

## Downloads

- Web ZIP: for an HTTPS host or itch.io HTML upload; not a double-click offline app.
- Windows x86_64 ZIP: extract completely and run `LibreTabs.exe`.
- Linux x86_64 ZIP: extract completely and run `./libretabs.x86_64`.

Native builds are unsigned. Download only from this project's release page and
verify `SHA256SUMS`. Do not disable operating-system security protections; report
blocked launches with the OS and message. No Godot installation is required.

## Known limits and feedback

Microphone listening detects one note at a time; chords and overlapping notes are
not assessed. Ringing strings, piano sustain, speaker bleed, or background noise
can confuse it, and hands-free phrases may be mistaken for music. The tuner and
commands have synthetic-signal tests, but have not been compared with physical
instruments and tuner hardware. Sustained browser microphone detection needs a
normally performing device test; the managed software-rendered Chromium preview
was too slow to establish that result. Actual Safari, Firefox, Windows runtime,
and physical MIDI-controller behavior remain unverified.

Generated guitar arrangements, simplified notation, and procedural sounds are
still under evaluation. The six-lesson course is not complete. Imported MIDI is
session-only and stays on the device. Settings are saved locally when available;
no audio or playing history is uploaded.

Report the version, OS/browser, device, steps, expected result, and actual
result through https://github.com/bluehexagons/libretabs/issues. Use original
or redistributable MIDI reproductions and remove private filenames and personal
details from screenshots.
