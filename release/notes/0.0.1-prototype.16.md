# LibreTabs 0.0.1-prototype.16

Saved settings and a manual learning checklist for testing.
[Open LibreTabs](https://bluehexagons.github.io/libretabs/).
Finish your session and reload after updating; check the version in
**Menu → About LibreTabs**.

## Settings

Regular reading mode, on-screen keyboard visibility/feedback, library sorting and
tuner instrument/sensitivity/reference now survive reopening. Existing sound,
appearance, interface and music layout preferences continue to be saved.
Microphone/controller activation, calibration and temporary muting remain
session-only. Imported music and its tempo, position, part and loop are not saved.

**Settings → Reset settings → Restore defaults** restores practice/display
defaults, pauses playback and stops capture. It keeps the current piece and all
learned marks. Quick start returns on the next launch. Cancel changes nothing.

## Learned pieces

Check **Learned** on a library card, or **I've learned this piece** for the current
song, exercise or imported MIDI. Check it whenever you feel ready; uncheck it to
return to it. Playback and tuner feedback never mark a piece automatically.
Choose **To learn** or **Learned** to filter the library.

**Settings → Learning progress** shows totals. Its separate **Clear learned
marks** confirmation removes marks while preserving settings. Progress stays in
this device's app profile/browser storage, without an account or synchronization.
Imported pieces use a fingerprint; reopen the same MIDI to see its mark, even
after renaming it. No imported names, music or performed notes are saved.

Unreadable/newer saved data is preserved, failed saves show a notice, and stale
sessions cannot overwrite another session's marks. Reopen to load saved changes.

## Manual checks

- Change reading, sound and tuner choices, then reopen. Confirm choices return
  with the microphone off and no temporary song mute.
- Mark a song and an exercise learned, use the library filters, and reopen.
  Reopen a renamed imported MIDI to check its mark too.
- Cancel settings reset, then restore defaults and confirm marks stay. Test
  clearing marks separately. These actions do not clear cached app resources.
- Try all four interfaces on a phone in portrait/landscape and at 200% text.
  Reach the checkboxes, filters and confirmation buttons with touch/keyboard.

The full local verifier and bounded storage/restart tests pass. Physical
phone/microphone, Windows, other browsers and independent audible timing still
need manual testing. Musical/platform acceptance and the lesson course remain
open. Native packages are unsigned; verify SHA256SUMS and extract ZIPs completely.
Report version, interface, device/input setup and reproduction steps at
https://github.com/bluehexagons/libretabs/issues.
