# LibreTabs 0.0.1-prototype.8

Evaluation prototype, not the completed lesson-based MVP.

[Play and read the practice guide](https://bluehexagons.github.io/libretabs/).
If an older cached player appears after updating, finish your session and reload.

## What changed

- Drag sideways across scrolling music to seek. A tap still seeks directly; vertical gestures remain for page scrolling. The touch preview now disappears when a gesture ends.
- Restart is beside Play on ordinary portrait and larger screens. It returns to the song or loop start and keeps playing if playback was already active.
- Quick start and Menu → Practice layouts offer direct guitar, pick-strum, fingerpick, bass-staff, and piano choices. Piano includes concert-pitch treble and bass staffs, optionally with sounding piano keys.
- A new original two-hand piano exercise provides low and high notes in one MIDI part. Bass-staff and piano views show pitch names instead of guitar fret cues.
- Touch menus scroll with the finger's travel and stop when it stops. Dropdown choices open in a scrollable sheet so dragging through a list does not select an item.

## Useful checks for testers

- On a phone, drag the score sideways to seek, then drag a menu starting on a button, a dropdown, and a text area. Each scroll should stay controllable without activating the touched item.
- While playing, press Restart. Try it with an active loop too. Confirm the score and sound restart together.
- Choose the piano layout and its exercise from Quick start. Check both staffs and the pitch cue, then switch to guitar or bass-staff reading in Practice layouts.
- Try a long dropdown, reduced motion, a short landscape screen, Theater on a wide display, and both browser players. Report the device and browser with any confusing result.

## Downloads

- Web ZIP: for an HTTPS host or itch.io HTML upload; not a double-click offline app.
- Windows x86_64 ZIP: extract completely and run `LibreTabs.exe`.
- Linux x86_64 ZIP: extract completely and run `./libretabs.x86_64`.

Native builds are unsigned. Download only from this project's release page and
verify `SHA256SUMS`. Do not disable operating-system security protections; report
blocked launches with the OS and message. No Godot installation is required.

## Known limits and feedback

Guitar tabs still mean six-string E-standard guitar. The bass staff has no bass
fingering. Piano's middle-C split is a reading aid, not a source hand assignment;
separate imported MIDI parts are not automatically combined. Procedural audio,
simplified notation, and generated guitar arrangements remain under evaluation.
The six-lesson course is not complete. Imported MIDI is session-only and stays
on the device. Automated and VM browser checks do not establish performance on
every phone, TV, or browser.

Report the version, OS/browser, steps, expected result, and actual result through
https://github.com/bluehexagons/libretabs/issues. Use original or redistributable
MIDI reproductions and remove private filenames and personal details.
