# LibreTabs 0.0.1-prototype.19

This evaluation build makes options easier to find and fixes browser input
recovery. It also shortens the normal development and release checks.

- Menu and Settings now share six categories with summaries and responsive
  cards. Find an option searches translated names and setting labels; Enter
  opens the first result. Back restores the previous section, search, scroll
  position and keyboard focus. Close returns directly to practice.
- Appearance & text groups readability, theme, control placement and motion.
  Labeled controls have fewer redundant hover hints. The guide and in-app
  directions use the current category paths.
- The first Use microphone in practice action now keeps its request while
  capture starts. Cancelled microphone startup cannot overwrite the device
  list of a replacement session. Stale MIDI device-change callbacks cannot
  interrupt a new connection or discard its queued notes.
- Release checks reject incomplete or malformed offline asset inventories.
  Development readiness checks use the installer's actual web-template list.
- For contributors, the standard full gate took about one minute in the managed
  Debian checkout, down from over seven minutes. Broad UI matrices and the extra
  editor audit are completely optional through `--extended`; quick checks and
  focused categories support everyday work.

Please try finding an option, navigating Back, and closing the menu on a narrow
screen or with enlarged text. Try the first microphone practice action and
cancel/reconnect input setup. Device lifecycle regressions use simulated input;
physical MIDI and microphone behavior still need testing on your hardware.

[Practice guide, browser player and downloads](https://bluehexagons.github.io/libretabs/)

This remains an evaluation prototype with procedural audio, simplified notation
and no completed six-lesson course. Imported MIDI stays on the device and is
session-only. Independent audible timing, Windows/CachyOS runtime, physical
instruments, and musician/beginner acceptance remain open validation areas.
Native packages are unsigned. Verify `SHA256SUMS` and report blocked launches
with the OS and message; do not disable operating-system security protections.
