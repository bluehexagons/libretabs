# LibreTabs 0.0.1-prototype.11

Evaluation build for human testing, not the completed lesson-based course.

[Play and read the practice guide](https://bluehexagons.github.io/libretabs/).
If an older cached player appears after updating, finish your session and reload.

## What changed

- **Songs** now has 16 local, project-authored teaching arrangements. New short
  versions of *Row, Row, Row Your Boat*, *Jingle Bells*, and *Greensleeves* broaden
  the suggested skill range. Search, filters, and sorting help you browse by
  title, duration, starting tempo, suggested level, and instrument.
- **Listen** plays up to 12 seconds from a song's first note so you can recognize
  it before choosing **Try**. A preview pauses practice audio but keeps the
  current song and position. It follows your selected sound, instrument volume,
  and effects; leaving Songs stops it.
- The Songs browser uses clearer icons and compact cards. Search, Import MIDI,
  Filters, and the first song choices are visible together on phone screens.
  Layout choices stay open while you compare them, and Tuner & listening is
  easier to reach. Dragging the practice score scrolls naturally; a tap still
  selects a note.

## Useful checks for testers

- Find a familiar tune by listening before reading its title. Switch between
  previews, then press **Try**; report any unexpected change to the previously
  open song, position, or sound level. Set instrument volume to zero and confirm
  that a preview is silent.
- Search and filter the library at narrow and wide window sizes. Increase text
  size, use keyboard focus, and try light and dark appearances. Confirm that
  titles, metadata, Listen, and Try remain readable and reachable.
- On a touch screen, drag the score to browse and tap a note to select it.
  Check that opening and changing a layout does not close its settings panel.

## Downloads

- Web ZIP: for an HTTPS host or itch.io HTML upload; not a double-click offline app.
- Windows x86_64 ZIP: extract completely and run `LibreTabs.exe`.
- Linux x86_64 ZIP: extract completely and run `./libretabs.x86_64`.

Native builds are unsigned. Download only from this project's release page and
verify `SHA256SUMS`. No Godot installation is required.

## Known limits and feedback

Levels and suggested instruments are editorial hints, not verified performance
grades. The songs are short teaching arrangements, not authoritative editions.
Generated guitar fingerings, simplified notation, and procedural sounds remain
under evaluation. Imported MIDI stays on the device for the current session.

Microphone listening still estimates one note at a time; chords and overlapping
notes are not assessed. Physical-instrument, tuner-hardware, Safari, Firefox,
Windows runtime, and physical MIDI-controller checks remain open. Please report
the version, OS/browser, input and audio devices, steps, expected result, and
actual result at https://github.com/bluehexagons/libretabs/issues. Use original
or redistributable MIDI in reports and remove private details from screenshots.
