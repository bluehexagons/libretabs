# LibreTabs 0.0.1-prototype.3

Responsive layout and onboarding refinement build. LibreTabs remains an
incomplete evaluation prototype intended to gather usability, device, timing,
and musical feedback.

[Play in a browser or read the practice guide](https://bluehexagons.github.io/libretabs/)

## Changes in this build

- Added a startup Quick start guide for the first exercise. It explains the six
  tab lines, frets, playback, tempo, metronome, looping, and the upcoming-note
  highlights before practice begins.
- Added a saved **Show on startup** preference. Menu → Quick start and Help can
  reopen the guide and re-enable it at any time.
- Kept the paired score inside the available player height at short and tall
  window sizes by removing secondary context and scaling the music proportionally
  when necessary. Normal practice no longer gains a main-area scrollbar in the
  tested layouts.
- Redesigned compact manual-page navigation as large previous/next controls with
  a centered page counter. Page turns never seek playback; Score view retains
  playback-following support.
- Improved narrow and short-landscape layouts, including side controls, large
  text, header actions, tempo controls, notices, and menu headers.
- Long imported names now remain usable in dropdowns without expanding them past
  the screen. Full names remain available as hover help.
- Smoothed the background wave tile and kept score borders and clef gutters
  inside their rounded frames.

## Downloads

- Web ZIP: for an HTTPS host or itch.io HTML upload; it is not a double-click
  offline application.
- Windows x86_64 ZIP: extract completely and run `LibreTabs.exe`.
- Linux x86_64 ZIP: extract completely and run `libretabs.x86_64`.

Native builds are unsigned. Download only from this project and verify the files
against `SHA256SUMS`. Do not disable operating-system security protections; report
a blocked launch with the operating system and exact message. Godot is not needed
to run the native packages.

## Evidence and known limits

The pinned Godot 4.7.2 build passes 6,287 core checks, 494 practice UI checks,
462 layout checks, 14 Python tests, five JavaScript tests, import/editor/boot
checks, and the deliberate failure-path check. Managed web export and browser
checks passed at desktop, portrait, landscape, and 200% text sizes.

The six-lesson course is incomplete. Audio is procedural, and notation and guitar
fingering have not completed musician review. MIDI imports are session-only and
remain on the device. Physical Windows and Linux launch testing, Safari and
mobile testing, independent audio-latency measurement, itch.io testing, and the
production VM deployment remain open. A successful export does not establish
compatibility with an untested device.

## Feedback

Report the version, operating system or browser, device, and reproduction steps
through [GitHub Issues](https://github.com/bluehexagons/libretabs/issues). Use only
original or redistributable MIDI reproductions, and remove private filenames and
personal details from screenshots.
