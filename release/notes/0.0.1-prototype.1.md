# LibreTabs 0.0.1-prototype.1

Initial packaging candidate for feedback. This is an evaluation prototype, not the
completed lesson-based MVP.

## Available to evaluate

- Local format-0/1 MIDI import and built-in original exercises.
- Synchronized staff/tab practice, tempo, metronome, count-in and looping.
- Keyboard reference notes, configurable controls, responsive themes and reduced motion.
- Printable practice pages and a capture/overlay view.

## Packages

Web ZIP requires an HTTPS host with cross-origin isolation (or configured itch.io
HTML hosting). Windows/Linux x86_64 ZIPs use native release runtimes and need no
Godot installation. Extract completely, then run LibreTabs.exe on Windows or
./libretabs.x86_64 on Linux. Builds are unsigned; report blocked launches without
disabling operating-system protections. Verify SHA256SUMS before testing.

## Known limits

The six-lesson course is incomplete. Audio is procedural and notation/fingering
are simplified and not musician-reviewed. MIDI imports are session-only, capped
at 256 KiB, and stay on your device. Physical-device timing, Windows launch and
actual itch.io/Safari/mobile behavior still need recorded evaluation. Export
success is not a compatibility guarantee. See docs/releases.md for the test plan.

Report the version, OS/browser and reproduction steps at
https://github.com/bluehexagons/libretabs/issues. Share only MIDI you may redistribute.
