# LibreTabs 0.0.1-prototype.15

Interface comparison build for manual testing. Musical/platform acceptance
remains open; a final redesign has not been selected.

[Open LibreTabs](https://bluehexagons.github.io/libretabs/).
Finish your session and reload after updating. Check the version in
**Menu → About LibreTabs**.

## Try the interfaces

Open **Menu → Interface**, select a choice, then **Done**:

- **Classic** keeps the current player and your chosen control edge.
- **Focus** removes secondary shortcuts and uses a small Play/speed group.
- **Touch** groups controls at the bottom, with simpler navigation. Short
  landscape screens place controls on your preferred hand side.
- **Workspace** adds a controls rail and direct settings shortcuts on wide
  screens. Narrow windows and enlarged text use the compact player.

Classic remains the default. Switching reuses the current song, score, timeline,
loop, speed and listening connection. The choice is saved on this device.
Theater/capture retain their shared views; music layout and appearance are
separate choices. Selected interface buttons have a check icon.

## Refactoring and fixes

Shared widget construction and responsive layout now live in separate modules.
New presentation providers use viewport/text/handedness values without owning
audio, imports or a clock. See `src/ui/interfaces/README.md` to add a candidate.
The existing application bridge and several settings panels remain shared.

Listening controls now stack their groups when their labels exceed the available
wide-screen width, including 200% text. Browser preference keys use one allow-list;
interface persistence, blocked storage and unrelated-key rejection have tests.

## Manual comparisons

- Try each candidate on a phone in portrait/landscape and on a desktop/tablet.
  Try 100/150/200% text, both hands and a visible browser toolbar. Reach every
  control with touch/keyboard; scroll Workspace's rail when needed.
- Switch while playing, paused, looping and listening. Confirm no restart,
  permission prompt, lost input setting or unexpected change to music layout.
- Reload after selecting a candidate. Test denied/unavailable device storage.
- Enter/leave Theater and capture; verify return navigation. Compare light,
  dark and midnight, reading comfort and how easily you find the next action.

The microphone detects one note at a time. Music-only mute retains clicks; use
headphones to keep speaker sound out of microphone input. Physical phone/piano,
Windows, Firefox/Safari and independent timing checks remain open. Prefer the
main player or native app; the compatibility player has weaker timing expectations.
Native builds are unsigned. Verify SHA256SUMS and extract ZIPs completely.

Report the version, interface, viewport/device, input setup and reproduction
steps at https://github.com/bluehexagons/libretabs/issues.
