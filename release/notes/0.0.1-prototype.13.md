# LibreTabs 0.0.1-prototype.13

Evaluation build for manual testing. Musical and platform acceptance remain open.

[Play and read the practice guide](https://bluehexagons.github.io/libretabs/).
Finish your session and reload after an update. Check the running version in
**Menu → About LibreTabs**.

## Changes since prototype.12

- Switch **Smooth scrolling** and one-to-six-line pages directly from the
  Music lines dropdown beside the player.
- After browsing manually, Play/Pause becomes **Back to current note**.
  Pressing it re-centers without starting or pausing playback. Space still
  plays or pauses.
- Printed music joins measures into regular rows, with more room for crowded
  passages and less repeated labeling. Saved filenames include the song title.
- The tuner uses a stable note display, a smoother needle, direction arrows and
  state icons. Song cards separate titles, credits and details. More player and
  menu actions have SVG icons; rest and keyboard instructions are clearer.

## Manual checks

- Switch scrolling/pages in regular and Theater views. Browse while playing and
  paused, then use Back to current note. Confirm playback state stays the same.
- Print a familiar song as staff, tabs and both, on A4/Letter. Check row starts,
  barlines, spacing and filenames; disable browser headers/footers.
- Tune one steady note. Check low/center/high indications, note changes, silence
  and Tuner on/off. Try an electronic piano at a comfortable speaker volume.
- Browse Songs at phone size and 200% text. Test keyboard focus, Light/Dark/
  Midnight appearance, and the player dropdown icons.

## Downloads and known limits

Web ZIP requires an HTTPS host. Extract native ZIPs completely, then run
LibreTabs.exe on Windows or ./libretabs.x86_64 on Linux. Native packages are
unsigned; verify SHA256SUMS and keep operating-system protections enabled.

The tuner estimates one note at a time; it does not assess chords. Notation,
guitar fingering and procedural sound remain prototype projections. Physical
phone, piano/microphone, printer, Windows, Firefox/Safari and independent timing
acceptance still need testing. The compatibility web player's audio stalled
in prior T3 Code tests; use the preferred player or native package for practice.

Report the running version, device/browser, audio/input setup and reproduction
steps at https://github.com/bluehexagons/libretabs/issues.
