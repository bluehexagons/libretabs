# LibreTabs 0.0.1-prototype.17

This evaluation build addresses button alignment, overlay controls, interface
comparison and tuner response.

- Icon-only buttons center their icons, including the wide Play target.
- Capture & overlay opens a preview with Play/Pause, Settings and Back. Clean
  frame hides the toolbar; tap or F10 shows it again. The mouse pointer stays
  visible. LibreTabs still uses other software for recording.
- Focus is a plain music stand with a top toolbar. Touch has navigation tabs
  and a separate wide Play action when height permits. Workspace has a labeled
  controls rail and a score setup panel on large screens. Try Menu → Interface.
- The tuner corrects a measured sharp interpolation bias, accepts softer
  electronic-piano input by default and checks fresh audio more frequently.
  The display filters brief shaky readings without changing practice feedback.

Please retest electronic piano through its speakers into a phone microphone,
first with the saved sensitivity and then with the default setting. Compare
several low, middle and high notes, pickup distance and response when changing
notes. For acoustic guitar, compare needle steadiness and sustained readings
with the same external tuner. A4 defaults to 440 Hz; the reference is adjustable
in Input settings. Play single notes for microphone listening.

Try capture preview in portrait and landscape, including Clean frame, tap/F10
to reveal controls and Escape to return. Switch interfaces while paused and
playing; check small screens and enlarged text as well as desktop layouts.

Synthetic pitch tests and native rendering checks pass. They do not certify
physical microphone accuracy, phone response time, OBS integration or browser
audio timing. Collaborative browser inspection encountered T3 capture/navigation
failures; web interaction remains a manual check. This remains an evaluation
prototype, with musician, beginner and physical-platform acceptance still open.
