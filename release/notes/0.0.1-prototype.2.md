# LibreTabs 0.0.1-prototype.2

First public evaluation build. LibreTabs is still an incomplete prototype; this
release is intended to gather usability, device, timing, and musical feedback.

[Play in a browser or read the practice guide](https://bluehexagons.github.io/libretabs/)

## Available to evaluate

- Open a local format-0 or format-1 MIDI file, select a part, and practice it
  without uploading the file.
- Follow synchronized guitar tablature and staff notation with current and
  upcoming-note highlights, smooth scrolling, page views, seeking, and loops.
- Adjust tempo, starting BPM, count-in, metronome, instrument and click volume.
- Play reference notes from either keyboard-row mapping and save display,
  accessibility, playback, handed-layout, and control-position preferences.
- Use responsive light/dark layouts, reduced motion, printable practice pages,
  and a capture overlay intended for streaming or instructional video.
- Play the threaded or compatibility web build through GitHub Pages, or download
  unsigned Windows and Linux x86_64 packages from this release.

## Downloads

- Web ZIP: for an HTTPS host or itch.io HTML upload; it is not a double-click
  offline application.
- Windows x86_64 ZIP: extract completely and run `LibreTabs.exe`.
- Linux x86_64 ZIP: extract completely and run `libretabs.x86_64`.

Native builds are unsigned. Download only from this project and verify the files
against `SHA256SUMS`. Do not disable operating-system security protections; report
a blocked launch with the operating system and exact message. Godot is not needed
to run the native packages.

## Evidence and known limits

The pinned Godot 4.7.2 build passes the repository's automated parser, model,
transport, layout, interaction, service-worker, export, and application-boot
checks. Chromium testing confirmed that the public GitHub Pages threaded and
compatibility players render, and that the threaded player remains isolated on
an offline reload.

The six-lesson course is incomplete. Audio is procedural, and notation and guitar
fingering have not completed musician review. MIDI imports are session-only,
capped at 256 KiB in this prototype, and remain on the device. Physical Windows
and Linux launch testing, Safari and mobile testing, independent audio-latency
measurement, itch.io testing, and the production VM deployment remain open. A
successful export does not establish compatibility with an untested device.

## Feedback

Report the version, operating system or browser, device, and reproduction steps
through [GitHub Issues](https://github.com/bluehexagons/libretabs/issues). Use only
original or redistributable MIDI reproductions, and remove private filenames and
personal details from screenshots.
